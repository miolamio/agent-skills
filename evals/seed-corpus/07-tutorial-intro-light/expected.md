# Урок 1: знакомство с pandas

В этом уроке вы научитесь читать CSV-файл и фильтровать строки по условию. Pandas работает с табличными данными так же удобно, как Excel, но в коде.

## Установка

```bash
pip install pandas
```

## Первый DataFrame

```python
import pandas as pd
df = pd.read_csv("sales.csv")
df.head()
```

После этого мы сможем выбирать колонки, фильтровать строки и считать агрегаты. Полный справочник методов есть в официальной документации.
