# Аутентификация: краткая справка

API использует JWT-токены. Время жизни access-токена — 1 час, refresh-токена — 30 дней.

Чтобы получить токен, отправьте POST на `/auth/login` с полями `email` и `password`. Ответ содержит `access_token`, `refresh_token` и срок действия.

Все последующие запросы должны передавать токен в заголовке `Authorization: Bearer <token>`. При истечении срока вернётся 401 — используйте refresh-токен для обновления.
