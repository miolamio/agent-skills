# Начало работы с DataFlow CLI

DataFlow CLI — мощный инструмент командной строки для управления потоками данных. В этом руководстве мы погрузимся в основы работы и научимся выполнять базовые операции.

## Установка

В современном мире разработки скорость установки очень важна. Поэтому мы сделали процесс максимально простым:

```bash
npm install -g @dataflow/cli
```

После установки проверьте, что всё работает:

```bash
dataflow --version
```

## Первый проект

Стоит отметить, что DataFlow организует работу вокруг концепции "проектов". Эта команда создаст структуру каталогов:

→ `config/` — конфигурационные файлы
→ `pipelines/` — определения пайплайнов
→ `data/` — локальные данные
→ `logs/` — логи выполнения

## Запуск

Важно понимать, что пайплайн — основная единица работы в DataFlow. Запустим:

```bash
dataflow run example
```

Поздравляем -- вы только что выполнили первое преобразование данных.
