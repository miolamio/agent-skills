# Начало работы с DataFlow CLI

DataFlow CLI — инструмент командной строки для управления потоками данных. В этом руководстве разберём основы и научимся выполнять базовые операции.

## Установка

```bash
npm install -g @dataflow/cli
```

После установки проверьте, что всё работает:

```bash
dataflow --version
```

## Первый проект

DataFlow организует работу вокруг концепции «проектов». Эта команда создаст структуру каталогов:

- `config/` — конфигурационные файлы.
- `pipelines/` — определения пайплайнов.
- `data/` — локальные данные.
- `logs/` — логи выполнения.

## Запуск

Пайплайн — основная единица работы в DataFlow. Запустим:

```bash
dataflow run example
```

Готово — вы только что выполнили первое преобразование данных.
