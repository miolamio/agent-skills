# Почему я больше не пишу README первым

Раньше я начинал каждый проект с README. Это казалось дисциплиной — план до кода. Но за пять лет привычка превратилась в самообман: README писался один раз и устаревал к первому коммиту.

Теперь я пишу его последним. Сначала — рабочий прототип, потом — описание того, что получилось. README перестал быть фантазией и стал документацией.
