# Заметка о выходе релиза 2.4

Релиз 2.4 опубликован во вторник вечером. Он добавляет линтер для русских текстов и исправляет шесть ошибок, найденных в бета-фазе.

Подробный список изменений лежит в файле CHANGELOG. Установка занимает одну команду, миграции данных не требуются. Если возникнут вопросы по обновлению, напишите в канал поддержки.
